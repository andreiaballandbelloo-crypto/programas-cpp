# 📚 Programas em C++ - Introdução à Programação

Este repositório reúne os programas desenvolvidos durante a disciplina de **Introdução à Programação**.

Os arquivos presentes aqui representam minha evolução no aprendizado da lógica de programação, desde os primeiros exercícios até conceitos mais avançados abordados ao longo da disciplina.

## 📖 Conteúdos estudados

Durante o desenvolvimento desses programas, foram praticados diversos conceitos fundamentais da programação, como:

- Entrada e saída de dados;
- Variáveis e tipos de dados;
- Operadores aritméticos, relacionais e lógicos;
- Estruturas condicionais (`if`, `else` e `switch`);
- Laços de repetição (`for`, `while` e `do-while`);
- Funções;
- Vetores;
- Matrizes;
- Utilização de bibliotecas;
- Resolução de problemas utilizando lógica de programação.

Cada programa representa um exercício proposto em aula ou uma atividade desenvolvida para fixação dos conteúdos, permitindo acompanhar a evolução dos conhecimentos adquiridos durante a disciplina.

## 🛠️ Linguagem utilizada

- C++

## 🎯 Objetivo

Este repositório tem como objetivo registrar meu aprendizado em programação, servir como material de consulta e documentar minha evolução ao longo da disciplina de Introdução à Programação.
